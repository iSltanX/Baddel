# GIF العرض — السيناريو والمقاسات

يسجّله سلطان بنفسه، ثم يُحوَّل بالأمر في آخر الملف ويوضع في `docs/assets/demo.gif`، ويحلّ محلّ صورة الإشعار أعلى README (مكانه معلَّم بتعليق HTML في README.md وREADME.en.md).

## الفكرة في جملة

«اثممخ» تصير `hello` بضغطة واحدة، ويظهر الإشعار، ويتبدّل التخطيط فتكمل الكتابة بالإنجليزية. **6–8 ثوانٍ، بلا تعليق ولا مؤثرات.**

## التجهيز

| البند | القيمة |
|---|---|
| التطبيق | TextEdit، مستند جديد فارغ (**تنسيق ← اجعله نصًّا عاديًا**) |
| الخط | SF Pro أو Almarai بحجم 28pt، حتى يُقرأ بعد التصغير |
| المظهر | فاتح (يطابق الغلاف الفاتح). ونسخة داكنة اختيارية لاحقًا |
| مصدر الإدخال عند البدء | **Arabic** |
| إعدادات بدّل | «بدّل لغة لوحة المفاتيح بعد التحويل» مفعّل · «أظهر إشعار التحويل» مفعّل · الصوت مطفأ |
| الـDock | مخفي تلقائيًا، حتى يظهر الإشعار قرب أسفل الشاشة داخل منطقة التسجيل |
| النافذة | في وسط الشاشة أفقيًا، وأسفلها قريب من أسفل الشاشة. **الإشعار يظهر في منتصف أسفل الشاشة**، فيجب أن تشمله المنطقة |
| الإشعارات الأخرى | «عدم الإزعاج» مفعّل، ولا شيء خاص ظاهر على الشاشة |

## المنطقة

- سجّل بـ<kbd>⌘</kbd><kbd>⇧</kbd><kbd>5</kbd> ← **سجّل الجزء المحدَّد**، بنسبة **16:9**: مثلًا **960×540pt** تشمل أسفل نافذة TextEdit ومكان الإشعار تحته.
- لا تُظهر شريط القوائم. مؤشر التخطيط فيه صغير جدًا بعد التصغير، والإشعار يحمل شارة `EN` تكفي.

## اللقطات

| الزمن | ما يحدث |
|---|---|
| 0.0–0.6s | مستند فارغ والمؤشر يومض |
| 0.6–2.2s | اكتب «مرحبا » بالعربية، ثم **اثممخ** (كأنك نسيت تبديل اللغة). اكتب بإيقاع طبيعي لا سريع |
| 2.2–2.8s | توقّف لحظة، فيرى المشاهد الخطأ |
| 2.8s | اضغط <kbd>⌥</kbd><kbd>⇧</kbd><kbd>Space</kbd>: «اثممخ» تصير `hello`، ويظهر الإشعار «اثممخ ← hello» |
| 2.8–4.2s | اترك الإشعار يكمل ظهوره واختفاءه دون أن تلمس شيئًا |
| 4.2–6.0s | أكمل ` world` بالإنجليزية. هذا يثبت أن التخطيط تبدّل وحده |
| 6.0–7.0s | توقّف ثانية على النتيجة «مرحبا hello world»، ثم أوقف التسجيل |

**بديل (يعرض المدّ):** اكتب «اثممخ صخقمي» ثم اضغط الاختصار **مرتين** خلال ثانيتين، فتصير الكلمتان `hello world`. أطول بثانية، ويحتاج شرحًا في النص، فالأول أوضح لأول مشاهدة.

## التحويل إلى GIF

```bash
# من ملف .mov الذي يحفظه ⌘⇧5 (ffmpeg مثبّت عبر Homebrew)
ffmpeg -i demo.mov -vf "fps=15,scale=800:-1:flags=lanczos,split[a][b];[a]palettegen=max_colors=128:stats_mode=diff[p];[b][p]paletteuse=dither=bayer:bayer_scale=4:diff_mode=rectangle" -loop 0 docs/assets/demo.gif
```

- الناتج: **800px عرضًا** (يملأ عمود README في GitHub دون تكبير)، و15fps، ويتكرر بلا نهاية.
- الهدف أقل من **3MB**. إن زاد: اجعل `fps=12`، أو `max_colors=96`، أو قصّ الثواني الزائدة بـ`-ss` و`-t`.
- راجعه في المتصفح قبل اعتماده: هل يُقرأ «اثممخ» و`hello` بوضوح؟
