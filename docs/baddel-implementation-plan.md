# بدّل — Baddel · خطة التنفيذ

> كتبت «اثممخ» وأنت تقصد `hello`؟ اختصار واحد يصحّحها ويبدّل لغة لوحة المفاتيح.

أداة شريط قوائم لنظام macOS تحوّل النص المكتوب بتخطيط لوحة المفاتيح الخطأ
(عربي ⇄ إنجليزي) في أي تطبيق، محليًا بالكامل.

الاسم المقترح **بدّل** على وزن **نفّذ**: فعل أمر قصير يصف الوظيفة، وينسجم مع بقية المنظومة (رفّ، نفّذ، صَوْب).

## 1. نطاق الإصدار الأول (v1.0)

### داخل النطاق

| # | الميزة | الوصف |
|---|---|---|
| 1 | تحويل التحديد | حدّد نصًا ← اضغط الاختصار ← يُستبدل بالنص المصحَّح في مكانه. |
| 2 | تحويل آخر كلمة | بلا تحديد: يحدّد الكلمة السابقة للمؤشر ويحوّلها. تكرار الضغط يمدّ التحويل كلمةً أخرى للخلف. |
| 3 | كشف الاتجاه تلقائيًا | أغلبية المحارف عربية ← يحوّل إلى لاتيني، والعكس. |
| 4 | تبديل مصدر الإدخال | بعد التحويل ينتقل تخطيط النظام إلى اللغة الصحيحة لتكمل الكتابة. (قابل للتعطيل) |
| 5 | تراجع | الضغط مرة أخرى فورًا يعيد النص الأصلي. |
| 6 | إشعار HUD خفيف | كبسولة صغيرة تظهر ثانية واحدة: `اثممخ ← hello`. (قابلة للتعطيل) |
| 7 | خرائط ديناميكية | تُبنى من تخطيطات المستخدم المثبّتة فعلًا (Arabic / Arabic‑PC / Arabic‑QWERTY / ABC / US…)، لا جداول ثابتة. |
| 8 | استثناء تطبيقات | قائمة تطبيقات لا يعمل فيها الاختصار (الطرفية، مديرو كلمات المرور…). |
| 9 | شاشة ترحيب للصلاحيات | تشرح صلاحية Accessibility وسببها، وتتحقق منها حيًّا. |
| 10 | تشغيل عند الدخول + تحديث تلقائي | إضافتا Tauri: `autostart` و`updater`. |

### خارج النطاق (مؤجَّل عمدًا)

- التصحيح التلقائي أثناء الكتابة بلا اختصار. هذا يتطلب مراقبة كل ضغطات المفاتيح (Input Monitoring)، ويتعارض مع وعد الخصوصية. يُدرس في v2 كخيار اختياري صريح.
- لغات غير العربية والإنجليزية. البنية تدعمها لأن الخرائط ديناميكية، لكن الواجهة والاختبار للزوج العربي/الإنجليزي فقط.
- Mac App Store. الأداة تتحكم في تطبيقات أخرى عبر Accessibility، وهذا غير متاح داخل Sandbox.

## 2. القرار التقني

**Tauri 2: نواة Rust + واجهة Svelte/TypeScript.** (عُدّل في 2026-09-20. كان القرار الأول Swift أصيل.)

| المعيار | Tauri 2 / Rust | Swift |
|---|---|---|
| انسجامه مع بقية المنظومة (Luma ونفّذ: البناء والتوقيع والمحدِّث والخبرة نفسها) | ✅ | ✗ مسار جديد بالكامل |
| تصميم الواجهة | HTML/CSS: الخطان Cairo وAlmarai وRTL مباشرة، والتصميم يُراجَع في المتصفح وهو الواجهة الفعلية | عناصر النظام جاهزة، لكن التخصيص البصري أصعب |
| النواة قابلة لإعادة الاستخدام | ✅ `baddel-core` حزمة Rust: تدخل نفّذ مباشرة، وتصلح نواةً لـ`arabic-text-kit` | حزمة Swift معزولة عن بقية المشاريع |
| واجهات النظام (AX وTIS وCGEvent وUCKeyTranslate) | عبر FFI: `objc2` و`core-graphics` و`accessibility-sys` وتعريفات Carbon يدوية. ممكن، لكنه `unsafe` أكثر ويحتاج عزلًا صارمًا | مباشرة |
| الحجم / الذاكرة | نحو 8–10MB، والخمول خفيف بشرط ألا تبقى webview حيّة | نحو 3–5MB |

**ما يكلّفه هذا القرار وكيف نعالجه:**
- **`unsafe` في طبقة النظام:** يُحصر كله في `src-tauri/src/sys/` خلف واجهات آمنة، والنواة تبقى Rust صِرفًا.
- **سرقة التركيز:** نافذة webview قد تسحب التركيز من التطبيق الهدف، فيُبنى HUD **أصيلًا** (`NSPanel` عبر `objc2`)، والقائمة tray menu أصيلة.
- **الذاكرة:** نافذتا الإعدادات والترحيب تُنشآن عند الطلب وتُدمَّران عند الإغلاق.
- **أيقونة Liquid Glass (Icon Composer):** لا يدعمها مسار Tauri مباشرة. يصدر v1 بأيقونة `.icns` عادية، والباقي يؤجَّل.

- **الحد الأدنى:** macOS 13، Universal (Apple Silicon + Intel).
- **إضافات Tauri:** `global-shortcut` و`autostart` و`updater` و`store` و`process` و`dialog`.
- **بلا شبكة** باستثناء فحص التحديث (قابل للتعطيل). الخطوط والأصول محلية.

## 4. الخوارزمية

### 4.1 بناء الخريطة (`LayoutMap`)

1. عدّد مصادر الإدخال المفعّلة عبر `TISCreateInputSourceList`، واختر أول تخطيط عربي وأول تخطيط لاتيني (أو ما حدده المستخدم في الإعدادات).
2. لكل `keycode` في 0…50 ولكل طبقة معدِّلات `{بلا، ⇧، ⌥، ⌥⇧}`: استدعِ `UCKeyTranslate` على التخطيطين ← زوج `(نص_عربي, نص_لاتيني)`.
3. ابنِ قاموسين: `ar→en` و`en→ar`. عند التصادم (محرف ينتج من أكثر من مفتاح) تُقدَّم الطبقة الأدنى: بلا معدِّل، ثم ⇧، ثم ⌥.
4. المفاتيح بعض مخرجاتها **أكثر من محرف** (مفتاح B ← «لا»)، فتُخزَّن المفاتيح كسلاسل، والمحلِّل يطابق **الأطول أولًا**.
5. أعد البناء عند إشعار `kTISNotifyEnabledKeyboardInputSourcesChanged`.

### 4.2 التحويل (`Converter`)

```
convert(text):
  dir   = عدّ المحارف العربية مقابل اللاتينية ← الأغلبية تحدد الاتجاه
  out   = لكل موضع: طابِق أطول مفتاح في الخريطة، وإلا مرّر المحرف كما هو
          (المسافات والأرقام والرموز غير المعرّفة تمر بلا تغيير)
  إن كان الاتجاه ar→en وفي النص «لا»: مرّر على Disambiguator
  return out, dir
```

### 4.3 التباس «لا»

في التخطيط العربي: `b` ← «لا»، و`g`+`h` ← «ل»+«ا» = «لا» أيضًا. فـ«مهلاف» قد تكون `light` أو `libt`.

- ولّد كل الاحتمالات (2ⁿ، وn عادةً 1–2).
- اختر الاحتمال الموجود في قائمة الكلمات.
- إن لم يُحسم: الافتراضي `b` (الحرف أشيع من الثنائي `gh`).

### 4.4 مسار التنفيذ عند الضغط على الاختصار

```
1. IsSecureEventInputEnabled()؟  ← توقّف بصمت (حقل كلمة مرور)
2. التطبيق الأمامي في قائمة الاستثناء؟ ← توقّف
3. اقرأ التحديد:
     أ) AX: kAXSelectedTextAttribute من العنصر المركَّز
     ب) إن فشل: احفظ الحافظة ← ⌘C ← اقرأ (انتظر تغيّر changeCount، مهلة 150ms)
4. التحديد فارغ؟ ← KeySynth: ⌥⇧← (حدّد الكلمة السابقة) ثم أعد الخطوة 3
5. حوِّل النص
6. اكتب النتيجة:
     أ) AX: اضبط kAXSelectedTextAttribute
     ب) إن فشل: ضع النتيجة في الحافظة (موسومة Transient) ← ⌘V ← استعد الحافظة بعد 200ms
7. بدّل مصدر الإدخال إلى لغة النتيجة (TISSelectInputSource)
8. اعرض HUD، وخزّن (الأصل، النتيجة، الوقت) للتراجع
```

**التراجع / المدّ:** إن ضُغط الاختصار خلال ثانيتين من تحويل سابق والتحديد فارغ، تُمدّ العملية كلمةً أخرى للخلف. واختصار ثانٍ اختياري (⌘Z يعمل أصلًا في مسار اللصق) يعيد الأصل.

## 5. الصلاحيات والخصوصية

| الصلاحية | لماذا | ملاحظة |
|---|---|---|
| **Accessibility** | قراءة التحديد واستبداله + توليد ضغطات المفاتيح | الصلاحية الوحيدة المطلوبة. |
| Input Monitoring | غير مطلوبة | الاختصار العام عبر Carbon Hotkey لا يحتاجها. هذه نقطة تسويقية: «بدّل لا يرى ما تكتب». |

- لا سجل للنصوص المحوَّلة على القرص. التراجع في الذاكرة فقط ويُمسح بعد ثوانٍ.
- الحافظة تُستعاد دائمًا. المحتوى المؤقت يوسَم بـ `org.nspasteboard.TransientType` و`org.nspasteboard.ConcealedType` حتى يتجاهله رفّ وبقية مديري الحافظة (راجع [nspasteboard.org](http://nspasteboard.org)). **تحقّق أن رفّ نفسه يحترم هذين الوسمين.**

### ⚠️ تنبيه التوقيع

تطبيقاتك الحالية موقَّعة ad‑hoc. صلاحية Accessibility في نظام TCC مربوطة بتوقيع التطبيق. مع ad‑hoc يتغير التوقيع في كل بناء، **فيفقد المستخدم الصلاحية بعد كل تحديث** ويضطر لإعادة منحها. أمامك حلّان:

1. **Developer ID** (99$/سنة) + Notarization. هذا هو الحل الصحيح، ويزيل تحذير Gatekeeper عن كل تطبيقاتك أيضًا.
2. شهادة موقَّعة ذاتيًا **ثابتة** تُستخدم في كل الإصدارات. تحافظ على الصلاحية بين التحديثات، لكن يبقى تحذير Gatekeeper.

هذه الأداة تحديدًا هي أقوى مبرر للانتقال إلى Developer ID.

## 6. الحالات الطرفية

| الحالة | السلوك |
|---|---|
| حقل كلمة مرور / Secure Input | لا شيء، بلا HUD. |
| تطبيقات لا تدعم AX (بعض Electron، ألعاب) | السقوط إلى مسار الحافظة تلقائيًا. |
| الطرفية | ⌥⇧← لا تحدّد فيها، فهي مستثناة افتراضيًا ويبقى تحويل التحديد اليدوي متاحًا عبر الحافظة. |
| نص مختلط («اثممخ world») | التحويل **بالكلمة**: كل كلمة تُحوَّل حسب نصّها فقط إن كانت من لغة الأغلبية الخاطئة. في v1: يُحوَّل كل شيء حسب الأغلبية، وهذا بسيط ومتوقَّع. |
| حافظة فيها صورة/ملف | احفظ كل `pasteboardItems` بأنواعها كلها واستعدها كاملة. |
| تحديد ضخم (> 10 آلاف محرف) | ارفض مع HUD: «التحديد طويل جدًا». |
| لا يوجد تخطيط عربي مثبّت | شاشة الإعدادات تنبّه وتقترح إضافته. تُستخدم خريطة Arabic‑PC مضمَّنة كاحتياط. |
| التشكيل والهمزات (طبقة ⇧) | تغطيها الخريطة الديناميكية: `H` ← «أ» والعكس. |
| تعارض الاختصار مع تطبيق آخر | فشل التسجيل في `global-shortcut` يُظهر حالة «تعارض» في المسجِّل. الافتراضي المقترح: **⌥⇧Space** أو النقر المزدوج على ⇧ (v1.1). |

## 8. خطة الاختبار

**وحدة (آلي):** تحويل ذهاب وإياب `convert(convert(x)) == x` لكل مفاتيح الخريطة · حالات «لا» · نص مختلط · محارف غير معرّفة · سلاسل فارغة.

**مصفوفة يدوية** (تحويل تحديد + آخر كلمة + استعادة الحافظة):

| التطبيق | النوع | المسار المتوقع |
|---|---|---|
| TextEdit، Notes، Mail | AppKit | AX |
| Safari، Brave (حقول ويب) | WebKit/Chromium | AX ثم الحافظة |
| VS Code، Slack، Discord | Electron | الحافظة |
| Luma، نفّذ | Tauri | الحافظة |
| Figma، Notion (ويب) | Canvas/contenteditable | الحافظة |
| Terminal، iTerm | طرفية | مستثنى / تحديد يدوي فقط |
| Word، Pages | مكتبية | AX |
| Spotlight، Raycast | لوحات عائمة | تحقّق أن HUD لا يسرق التركيز |

## 10. ما بعد v1

- **v1.1:** النقر المزدوج على ⇧ كمشغِّل · تحويل بالكلمة للنص المختلط · تحويل آخر سطر.
- **v1.2:** إجراءات نصية إضافية بالآلية نفسها: أرقام عربية ⇄ هندية، إزالة التشكيل، إزالة الكشيدة. بهذا يصير «بدّل» نواة لفكرة «مُحوِّل».
- **v2:** اقتراح تصحيح تلقائي (اختياري، يتطلب Input Monitoring، مع شرح صريح).
- **تكامل:** أمر «بدّل» داخل نفّذ، وإجراء على عناصر رفّ («بدّل تخطيط هذا العنصر»). `baddel-core` حزمة Rust مستقلة أصلًا: تُستورد في نفّذ مباشرة، وتصلح نواةً لـ`arabic-text-kit`.
