# الخصوصية

آخر تحديث: 2026-10-01

بدّل أداة محلية بالكامل. هذه الصفحة تشرح ما يقرأه، وما يحتفظ به، وما يرسله.

- **القراءة**: فقط حين تضغط الاختصار — التحديد إن وُجد، وإلا النص قبل المؤشر بقدر ما يلزم لإيجاد الكلمة السابقة — أو حين تطلب التراجع، فيُقرأ موضع النص المحوَّل ليُعاد. لا يُقرأ شيء في غير ذلك.
- **التخزين**: لا نص على القرص ولا في أي سجل. آخر تحويل يبقى في الذاكرة 30 ثانية فقط ليتيح التراجع (أو نسخ النص الأصلي إن تعذّر التراجع)، ثم يُمحى. ملف الإعدادات في <span dir="ltr">`~/Library/Application Support/com.isltanx.baddel/`</span> يحمل التفضيلات وحدها (الاختصارات، الاستثناءات، وما شابه)، لا أي نص كتبته.
- **الحافظة**: تعود إلى ما كانت عليه بعد كل تحويل، إلا إن نسخت أنت (أو تطبيق آخر) شيئًا أثناءه، فيبقى الأحدث ولا يُكتب فوقه. ما يكتبه بدّل فيها يحمل وسمَي [nspasteboard.org](http://nspasteboard.org): «Transient» و«Concealed»، فتتجاهله مديرات الحافظة التي تحترمهما. **حدّ ذلك:** في التطبيقات التي لا تكشف نصّها، يضغط بدّل ⌘C، فيضع **التطبيق نفسه** النص المحدَّد في الحافظة نسخًا عاديًا بلا وسم. يستبدل به بدّل فورًا النص نفسه موسومًا، فلا يبقى بلا وسم إلا جزءًا من الثانية، لكن مدير حافظة يقرأ الحافظة في تلك اللحظة قد يسجّله. أما «انسخ النص الأصلي» في القائمة (بعد تراجع تعذّر) فنسخٌ تطلبه أنت، فهو عادي بلا وسم كأي نسخ.
- **الشبكة**: لا اتصال إلا في حالتين: فحص التحديث، وبلاغ تطلبه أنت وتؤكّده (البند التالي). فحص التحديث طلب واحد يوميًا لملف `latest.json` من صفحة إصدارات هذا المستودع على GitHub، يمكن إيقافه من **الإعدادات ← عام**. الطلب لا يحمل شيئًا عنك ولا عن نصّك، ويصل GitHub منه ما يصله من أي تنزيل عادي، مثل عنوان IP. روابط بدّل على GitHub في نافذة «حول» تفتح في متصفحك.
- **الإبلاغ عن مشكلة**: حين تختار «أبلغ عن مشكلة…» وتؤكّد الإرسال بعد المعاينة، وحينها فقط، يرسل بدّل طلبًا واحدًا إلى خادم على Cloudflare يملكه مطوّر بدّل، فيحفظه مسألةً في مستودع خاص على GitHub. يحمل الطلب ما عرضته المعاينة وحده: نوع المشكلة، ووصفك، وصورة إن أرفقتها (يُعاد ترميزها فتسقط بياناتها الوصفية، ولا يُرسل اسم ملفها)، ومعلومات تشخيص: إصدار بدّل وmacOS ونوع المعالج، ولغة الواجهة، وحالة الصلاحية والإدخال الآمن، ومعرّفا التخطيطين واسماهما، ونتائج آخر عشر محاولات تحويل ومسارها وزمنها وسبب التعذّر إن تعذّرت، بلا أي نص، ومعرّف التطبيق الذي كنت فيه في آخر محاولة، والإعدادات العامة (والاستثناءات عددًا لا أسماءً). **لا يُرسل** أي نص كتبته أو حوّلته، ولا محتوى الحافظة، ولا معرّف دائم لك أو لجهازك. يرى الخادم عنوان IP كأي طلب، ويستخدمه لحد عدد البلاغات بتجزئة مملّحة تنتهي مع مدتها، ولا يصل إلى المسألة. رقم البلاغ هو وسيلتك الوحيدة للمتابعة. وزر «انسخ معلومات التشخيص» في «حول» يضع الحقول نفسها في الحافظة دون أن يرسل شيئًا.
- **الصلاحية**: تسهيلات الاستخدام (Accessibility) هي الوحيدة المطلوبة — لقراءة التحديد أو الكلمة قبل المؤشر واستبدالها، وإرسال ضغطات النسخ واللصق حين لا يكشف التطبيق نصّه. لا يطلب بدّل مراقبة الإدخال (Input Monitoring)، ولا تسجيل الشاشة (Screen Recording)، ولا الوصول الكامل إلى القرص (Full Disk Access).
- **الحقول المحمية والاستثناءات**: في حقل كلمة مرور، أو حين يفعّل macOS الإدخال الآمن (Secure Input)، لا يقرأ بدّل شيئًا ولا يكتب شيئًا. و14 استثناءً افتراضيًا يتوقف فيها الاختصار: 7 طرفيات و7 من مديري كلمات المرور، تُدار من **الإعدادات ← الاستثناءات**.
- **لا تتبّع**: لا حسابات، ولا تحليلات، ولا تتبّع، ولا تقارير أعطال تلقائية.
- **التواصل**: لأي مشكلة، «أبلغ عن مشكلة…» من القائمة أو من «حول» يصل إلى المطوّر مباشرة دون حساب. ولسؤال عام، افتح مسألة في [صفحة المسائل](https://github.com/iSltanX/Baddel/issues)، وما تكتبه هناك علني.

# Privacy

Last updated: 2026-10-01

Baddel is fully local. This page explains what it reads, what it keeps, and what it sends.

- **Reading**: only when you press the shortcut — the selection if there is one, otherwise the text before the cursor, as far as needed to find the previous word — or when you ask for undo, which reads back the converted text to restore it. Nothing is read at any other time.
- **Storage**: no text is saved to disk or to any log. The last conversion stays in memory for 30 seconds only, to allow undo (or copying the original if undo can't go through), then it is dropped. The settings file at `~/Library/Application Support/com.isltanx.baddel/` holds preferences only (shortcuts, exceptions, and the like), never any text you typed.
- **Clipboard**: restored after every conversion — unless you (or another app) copied something meanwhile, in which case the newer copy stays and nothing is written over it. What Baddel puts on it carries the [nspasteboard.org](http://nspasteboard.org) markers "Transient" and "Concealed", so clipboard managers that respect them ignore it. **The limit:** in apps that don't expose their text, Baddel presses ⌘C, and **the app itself** puts the selected text on the clipboard as an ordinary, unmarked copy. Baddel replaces it at once with the same text, marked, so it stays unmarked for a fraction of a second — but a clipboard manager that reads the clipboard at that instant may record it. "Copy Original Text" in the menu (after an undo that couldn't go through) is a copy you ask for, so it is an ordinary, unmarked one like any other.
- **Network**: no network access except in two cases: the update check, and a problem report you ask for and confirm (next item). The update check is one request a day for `latest.json` from this repository's GitHub releases page, which can be turned off in **Settings → General**. The request carries nothing about you or your text; GitHub receives whatever any ordinary download request carries, such as an IP address. The GitHub links in the About window open in your browser.
- **Reporting a problem**: when you choose "Report a Problem…" and confirm after the preview — and only then — Baddel sends one request to a Cloudflare server run by Baddel's developer, which files it as an issue in a private GitHub repository. The request carries only what the preview showed: the problem type, your description, an image if you attached one (re-encoded, which drops its metadata; its file name is not sent), and diagnostics: the Baddel and macOS versions and processor type, the interface language, the Accessibility and Secure Input states, the identifiers and names of the two layouts, the outcome, path and duration of the last ten conversion attempts, and why one failed when it did, without any text, the identifier of the app you were in on the last attempt, and the general settings (exceptions as a count, not names). It **never** sends text you typed or converted, clipboard contents, or any persistent identifier for you or your device. The server sees your IP address, as with any request, and uses it only to rate-limit reports through a salted hash that expires with its window; it never reaches the issue. The report number is your only handle for follow-up. "Copy Diagnostics" in About puts the same fields on the clipboard without sending anything.
- **Permission**: the only permission Baddel asks for is **Accessibility** — to read the selection or the word before the cursor and replace it, and to send copy/paste keystrokes when an app does not expose its text. Baddel does not request Input Monitoring, Screen Recording, or Full Disk Access.
- **Protected fields and exceptions**: in a password field, or whenever macOS turns on Secure Input, Baddel reads nothing and writes nothing. There are 14 default exceptions where the shortcut does nothing: 7 terminals and 7 password managers, managed from **Settings → Exceptions**.
- **No tracking**: no accounts, no analytics, no tracking, no automatic crash reporting.
- **Contact**: for a problem, "Report a Problem…" in the menu or in About reaches the developer directly, without an account. For a general question, open an issue on the [issues page](https://github.com/iSltanX/Baddel/issues); what you write there is public.
